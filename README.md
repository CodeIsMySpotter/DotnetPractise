# DotnetPractise

This repository contains a series of .NET (primarily ASP.NET) projects and exercises. It serves as a personal workspace to learn, practice, and prepare for a role at Netwise.

## Purpose

The main goal of this repository is to systematically build up skills in the .NET ecosystem, focusing on web development with ASP.NET, clean architecture, and best practices relevant to real-world applications.
